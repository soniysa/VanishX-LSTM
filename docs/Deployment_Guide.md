# Deployment Guide

This project is designed to be easily deployed on various platforms. The easiest and most recommended platform for Streamlit applications is **Streamlit Community Cloud**.

## Option 1: Streamlit Community Cloud (Recommended)

1. **Push your code to GitHub:**
   Make sure `app.py`, `train.py`, `requirements.txt`, and the `models/` folder are committed to a public GitHub repository.
   *(Note: Ensure you run `train.py` locally first to generate the `.h5` files, and ensure they are smaller than 100MB to avoid Git LFS issues, or use Git LFS if needed).*

2. **Deploy:**
   - Go to [share.streamlit.io](https://share.streamlit.io/)
   - Click "New app"
   - Select your GitHub repository, branch, and specify the Main file path as `app.py`.
   - Click "Deploy!"

## Option 2: Render

1. Create a `render.yaml` file or configure via the Render Dashboard.
2. Select "Web Service".
3. Connect your GitHub repository.
4. **Build Command:** `pip install -r requirements.txt`
5. **Start Command:** `streamlit run app.py --server.port $PORT --server.address 0.0.0.0`
6. Click Deploy.

## Option 3: Hugging Face Spaces

1. Go to [Hugging Face Spaces](https://huggingface.co/spaces) and create a new Space.
2. Select **Streamlit** as the SDK.
3. Upload your files (`app.py`, `requirements.txt`, `models/`, `visualizations/`) directly to the HF Space via browser or git clone.
4. The space will automatically build and deploy based on the `requirements.txt`.

---
### Troubleshooting
- **Missing Models Error:** If the deployed app says models are missing, it means you didn't upload the `models/` directory generated by `train.py`.
- **Memory Limits:** If deployment fails due to memory, consider reducing the subset of text processed in `train.py` (e.g., lower `total_words` or sequence length) and re-upload the smaller models.
